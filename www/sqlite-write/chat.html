Lume · SQLite 写能力演示（examples/sqlite-write.lume，:8084）

本页独立于 invest 前端。该 profile 显式放行 sql_write——模型可建分析表、写入、查询；portfolio 镜像表只读，DROP/ALTER/PRAGMA 等被护栏拒绝。

护栏（agent-httpd src/agent/sqlite_tool.c）：sql_query 只读（SQLITE_OPEN_READONLY 物理只读）； sql_write 仅 INSERT / UPDATE / DELETE（UPDATE/DELETE 必须带 WHERE）或新建 CREATE TABLE； DROP / ALTER / TRUNCATE / VACUUM / ATTACH / PRAGMA / GRANT / REVOKE 与任何触碰 portfolio 镜像表的语句一律拒绝。对照：make invest（:8082）默认不含 sql_write，只读。
