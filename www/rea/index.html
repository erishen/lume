Lume × REA 概览 实时数据 Agent Chat

REA 逆向工程接入台

rea（Reverse Engineer Anything，morluto/rea）以 MCP server 形式常驻接入 lume 的 agent-httpd 客户端 —— 容器内 node + rea-agents@6.4.0 运行， 全部 rea__* 工具对聊天模型可见，resident 复用管道，无需每次握手。

能力分类

Native 二进制

Mach-O / ELF / PE：先 rea__open_binary 注入目标，再分析架构、段、符号、签名、依赖、调用图（深度分析需装 Ghidra / IDA / Hopper）

Go / Rust

内置静态解析：无需商业引擎即可读类型、函数、数据布局、指令

JS / Electron / .NET / SQLite

免商业引擎：JS bundle 分析、Electron 应用、.NET 程序集、SQLite 取证

Android

APK / ADB / JADX：清单、资源解码、apktool 客户端、WebView 脚本

Web

Chrome 系 CDP / Playwright：页面脚本导出、bundle 分析、会话观察

WASM / EVM / 固件 / pcap

字节码与合约接口、固件契约、网络包场景捕获
