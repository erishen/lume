Serena 源码语义接入台

Serena（oraios/serena，Oraios AI）以 MCP server 形式常驻接入 lume 的 agent-httpd 客户端 —— 容器内 python + serena-agent （LSP 后端）运行，全部 serena__* 工具对聊天模型可见。 与 rea-demo 互补：rea 是无源码时的二进制逆向，serena 是有源码时的 符号级语义分析（分析目标：容器内只读挂载的 lume 源码，clangd 提供 C/C++ 符号语义）。

能力分类

符号检索

serena__find_symbol / serena__get_symbols_overview：按名字或模糊匹配定位函数、类、变量、类型，拿定义位置与源码片段

引用与调用

serena__find_referencing_symbols：找出一个符号在所有文件里的引用；find_implementations / find_declaration 区分声明与实现

诊断

serena__get_diagnostics_for_file / get_diagnostics_for_symbol：语言服务器级别的编译诊断（错误/警告）

精确编辑

serena__insert_after_symbol / insert_before_symbol / rename_symbol / safe_delete_symbol：符号级原子编辑（本演示挂载只读，编辑预期失败，仅展示安全边界）

工程管理

serena__list_queryable_projects / serena__query_project：多项目切换；restart_language_server 兜底 LSP 卡死

语言覆盖

30+ 语言经 LSP：本容器装 clangd（C/C++ 主演示目标），可按需加 Python/TS 等语言服务器
